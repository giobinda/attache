# Security policy

Attaché performs privileged mount operations and is meant to protect data at
rest, so vulnerability reports are welcome.

**Please report privately.** Use GitHub's private vulnerability reporting:
the **Security** tab → **Report a vulnerability**
(<https://github.com/giobinda/attache/security/advisories/new>). Include what
you did, what you expected, and what happened; a proof of concept helps but a
clear description of the class of problem is enough to start.

Please don't open a public issue or pull request for a suspected
vulnerability until it has been fixed.

There is no formal disclosure timeline or bounty. This is a single-author
project maintained on a best-effort basis.
